Give Hermes a voice.

voicestudio connects Hermes to a locally running VoiceStudio server, the open-source AI voice studio. Clone a voice from a three-second sample. Dub any video into any language. Turn a script into a chaptered audiobook. All of it from a chat message, all of it on your machine.

01Install

Two ways in. The catalog route pins the exact commit a maintainer reviewed.

hermes plugins install voicestudio
hermes plugins enable voicestudio

Manual install. Point Hermes at the voicestudio/ subdirectory, which carries the manifest and the package together:

git clone https://github.com/aska-digital/protean-voice-studio
hermes plugins install ./protean-voice-studio/voicestudio

Prerequisite: the free, open-source VoiceStudio app running locally (default http://127.0.0.1:3900). Get it at voicestudio.sh, start it, then /vs-status tells you when it is back.

02Why this way

Voice AI as owned infrastructure, not rented SaaS. The plugin inherits that posture.

Your voices never leave the machine.

No API keys, no per-character billing, no audio uploaded to a vendor. The server is yours.

One surface for every voice job.

Speak, design, browse, narrate, dub, check. Six tools with one job each, each mirrored as a slash command.

Nothing to maintain.

Python stdlib only, no dependencies to rot. Catalog installs stay pinned to the reviewed commit.

03The tools

Each tool is mirrored as a slash command, and the bundled voice-studio skill ships usage guidance.

/vs-speak

vs_speak

Say it like you mean it.

Read short text aloud in a chosen voice and save it as an audio file. Up to about 6000 characters per take, with repeatable seeds.

/vs-design

vs_design_voice

Mirror a voice from three seconds.

Describe a voice in plain words, or clone one from a short wav or m4a sample. Saved for reuse, with a preview take.

/vs-voices

vs_list_voices

Every voice you own, one list.

Browse your saved voices, the shared gallery, and ready-made presets. Read-only and cheap. Call first when the user names no voice.

/vs-longform

vs_longform

Cast a script. Voice every role.

Turn a markdown script into chaptered audio. # headings split chapters, [voice:NAME] switches narrator mid-script. An interrupted render resumes with its job id.

/vs-dub

vs_dub

Any video, any language, same timing.

Dub a video into other languages using one of your voices. Reports per-language progress. Finished languages are kept if one fails.

/vs-status

vs_status

Is the studio awake?

Check that VoiceStudio is running, which engine is loaded, how many voices exist, and what is missing.

04In practice: an audiobook

A chaptered render, start to finish, in three messages.

/vs-voices --search narrator
/vs-longform --file episode.md --voice c79141c4 --format m4b \
  --title "Episode 12" --author "Aska Digital"

The plugin plans the chapters first, renders with progress, and fetches the finished .m4b with chapters intact. If the render is interrupted, rerun with --resume <job_id>. Nothing is lost.

Long-form scripts accept a closed markup set. Anything outside it is read aloud literally, so strip it first:

MarkupEffect
[pause], [pause 500ms]Silence, default or timed
[slow] / [fast] / [emphasis] / [spell]Delivery spans
[[word|say-this]]Pronunciation pin
[voice:NAME]Mid-script voice switch
# HeadingStarts a new chapter

06Little questions, short answers

Do I need the VoiceStudio app?

Yes. The plugin is a client for the app on your machine. Download it free at voicestudio.sh, start it, and run /vs-status.

Does my voice data leave my machine?

No. Everything travels between Hermes and your local VoiceStudio server. Dubbing uploads your video and cloning uploads your sample to that same local server. Nothing reaches a third party.

Can it clone anyone's voice?

It clones from a sample recording you provide. Use your own voice, or one you have the right to use.

Which Hermes version do I need?

0.21 or newer. The manifest declares requires_hermes: ">=0.21".

Is it in the plugin catalog?

The submission is in review. Until it lands, install manually from the repo URL.

What does it cost?

Nothing. The plugin is MIT. The VoiceStudio desktop app is free and open source.

07Disclosure

What the plugin does on your machine, for the record.

  • All network traffic stays between Hermes and your VoiceStudio server. Nothing is sent to third-party services.
  • vs_dub uploads your video file to the VoiceStudio server. vs_design_voice --sample uploads your sample recording. Both stay on your local server.
  • The plugin reads the script, video, and sample files you point it at, and writes generated audio under the plugin output directory (or the --out_path you give).
  • No credentials are read or stored. No telemetry. No self-updates: catalog installs stay pinned to the reviewed commit.
